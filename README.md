# イズミ装美 工事書類作成（一般用）

ChatGPTへのログインなしで使える一般公開版です。
会社・作業員・現場を入力し、「登録・保存」でブラウザ内へ保存できます。
帳票の「入力・修正」からの入力とA4印刷に対応します。
KY・労働災害発生時緊急連絡先はA4横、その他はA4縦です。

入力データは利用中のブラウザに保存し、サーバーや管理者へ送信しません。
別端末へ移す場合はバックアップ保存・読込を使用してください。
管理者用の登録済みデータ・原本写真は含めていません。
利用者の2026-11-24の指定により、提供された労働災害発生時緊急連絡先の26人分を初期値に含めています。変更した連絡先は各自のブラウザへ保存します。

2026-11-24更新：書類別の入力画面、入力に追従するプレビュー、常設の「登録・保存」、登録済み会社・作業員の選択、折りたたみ式の詳細入力。
編集元：既存プロジェクトの work/easy-ui.js・easy-ui.css。work/build-general.py で一般用HTMLのみを生成します。
一般用はGitHub Pagesで公開し、管理者用の既存システムは変更しません。
